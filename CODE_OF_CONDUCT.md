# Code of Conduct

## Our Standard

Be direct, technical, and respectful. Critique code and ideas — not people.

Unacceptable behavior: harassment, discrimination, personal attacks, or any conduct that makes contributors feel unwelcome.

## Enforcement

Violations reported to [sigilvoid@gmail.com](mailto:sigilvoid@gmail.com). Maintainer has final say on consequences, up to permanent ban.

## Scope

Applies to all project spaces: GitHub issues, PRs, discussions, and any other official channels.
